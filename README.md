# Slicing_Dream_Cafe
Pada tugas kali ini, saya membuat website katalog menu Dream Cafe dengan menerapkan konsep slicing website, yaitu mengubah rancangan desain UI. Pertama, kerangka halamannya dibuat menggunakan HTML untuk memuat teks, foto minuman, dan harga. Kemudian tampilannya dipercantik menggunakan CSS murni untuk mengatur warna latar, gaya font, tata letak kartu menu dua kolom, efek saat kursor diarahkan, serta memastikan tampilannya responsif di layar laptop maupun hanphone. Terakhir, saya menambahkan JavaScript melalui pemanfaatan DOM/Document Object Model, yaitu mekanisme untuk menghubungkan kode program dengan elemen di halaman web, yang saya terapkan pada tombol kategori all, coffee, dan non-coffee agar pengunjung bisa menyaring menu yang ingin dilihat secara langsung di layar tanpa halaman web harus dimuat ulang.
